# VaultBridge

VaultBridge 是一个独立维护的 Obsidian 同步插件，支持 S3、Google Drive 和
Dropbox。当前安装和配置说明见 [VaultBridge 设置指南（英文）](./personal/README.md)。

原 Remotely Save 中文文档保留在
[上游参考文档](./upstream-reference/README.zh-cn.md)，仅供历史参考，
其中的付费功能、安装步骤和服务链接不适用于 VaultBridge。

本项目保留所复用代码的许可证和署名。Linux/Android 及实际云服务测试已延后，
目前尚未验证。
